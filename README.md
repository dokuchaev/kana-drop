# Kana Drop

Kana Drop is a browser game for practicing hiragana. Type the romaji reading of
each falling kana to hit it with a shuriken. The game tracks score, mistakes,
and the best score saved in the browser.

## Requirements

- Node.js 22.17 or newer
- npm

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run check
npm run build
```
